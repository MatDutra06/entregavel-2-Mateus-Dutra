# Mateus-Dutra-Entregavel2

    O objetivo principal desse trabalho era analisar imagens dadas e fazer retângulos com o OpenCv a partir de coordenadas de tabelas csv's e mostra-las modificadas a partir dessa biblioteca. 

## Pré-requisitos para executar o código
- Possuir um editor de código capaz de executar Python e abrir janelas gráficas.
- Instalar a extensão OpenCV do Python.


## Instruções para executar o código
- Clonar esse repositório e abrir no seu terminal com um editor de código.
- Executar o código. 
- A tecla "espaço" avança as imagens e a tecla "Q" encerra o programa.

## Classes do código
- Deteccoes
    - Classe responsável por desenhar nas imagens,tem como atributos as coordenadas disponibilizadas nas tabelas csv.
- ImagemAnotada
    - Classe responsável por armazenar as cópias das imagens originais e também as detecções de cada imagem,com base em suas coordenadas.
